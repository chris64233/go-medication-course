# go-medication-course

本项目用于 GSB 评测，实现用药疗程与服药记录服务，帮助患者按处方完成一段有时间要求的用药计划。

## 功能

- 创建疗程：记录患者、药品、剂量、每日频次、开始时间与计划结束时间，拒绝缺失或明显不合理的剂量信息。
- 服药登记：支持按计划时间登记服药、漏服与补记；补记必须携带真实发生时间，系统同时保留登记时间用于追溯。
- 幂等确认：同一疗程同一计划时间重复提交返回已有记录，不会重复计数。
- 状态流转：疗程可暂停、恢复、完成、取消；已记录的服药事实保留，取消/完成/暂停后不能继续登记。
- 查询能力：按患者查询疗程、按疗程查询实际记录与漏服情况，结果按计划时间稳定排序。
- 错误提示：参数、日期与状态错误返回明确的业务错误（`ErrInvalidInput`、`ErrCourseNotFound`、`ErrInvalidStatusTransition`），不暴露内部异常。

## 代码结构

- `course.go`：疗程与服药记录的领域模型。
- `service.go`：内存版核心服务 `Service`，时钟可注入便于测试。
- `errors.go`：业务错误定义。
- `service_test.go`：创建、重复登记、补记、暂停/恢复、完成、取消与查询排序的自动化测试。

## 运行方式

需要 Go 1.23+。

```bash
# 运行全部测试
go test ./...

# 查看测试覆盖率
go test -cover ./...

# 构建
go build ./...
```
